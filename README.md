# 💸 Expense Manager

A clean and simple Expense Tracker built using React that helps you manage your daily expenses efficiently.

---

## 🚀 Features

- ➕ Add new expenses with title and amount  
- 🔍 Real-time search/filter functionality  
- 💾 Data persistence using localStorage  
- ❌ Delete expenses (if implemented)  
- 📱 Responsive and minimal UI  

---

## 🛠️ Tech Stack

- React (Hooks: useState, useEffect)
- JavaScript (ES6+)
- HTML5 & CSS3
- Vite (for fast development)
